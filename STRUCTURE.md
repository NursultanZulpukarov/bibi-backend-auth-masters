# Структура проекта bibi-backend

В этом документе описана архитектура и назначение основных директорий проекта. Пожалуйста, придерживайтесь этой структуры при добавлении нового функционала.


* **`app/api/v1/endpoints/`** — **Роутеры**. Здесь описываются конечные точки API (маршруты). Логика обработки запросов должна агрегироваться здесь или выноситься в отдельные сервисные слои при усложнении.
* **`app/models/`** — **SQLAlchemy модели**. Описание таблиц базы данных и связей между ними. Отражают реальную структуру БД.
* **`app/schemas/`** — **Pydantic схемы**. Используются для валидации входящих запросов (Request body, Query params) и сериализации ответов (Response model).
* **`app/core/`** — **Конфиги**. Сбор параметров из `.env`, управление секретами, глобальные настройки приложения (название проекта, CORS и т.д.).
* **`app/db/`** — **Подключение к БД**. Настройка сессий (AsyncSession/Session), генераторы для внедрения зависимостей (Dependencies) в роутеры.
* **`app/main.py`** — Инициализация FastAPI приложения, подключение роутеров, middleware и обработчиков событий (startup/shutdown).
